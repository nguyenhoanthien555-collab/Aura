# Skill: aura-android
## Role: AURA Android Companion & UI Automation
### Subsystem Capabilities:
- `android.foreground_app`: Package/activity detection.
- `android.ui_tree`: Dump and parse accessibility node hierarchy XML.
- `android.ui_search`: Locate target nodes by text, resource ID, or content-desc.
- `android.tap` / `android.swipe` / `android.text_input`: Injection via ADB.
- `android.screen_capture`: Downscaled screenshot capture for local vision models.
