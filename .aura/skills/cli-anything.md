# Skill: cli-anything
## Role: Agent-Native CLI Integration Framework
### Methodology:
1. DISCOVER: Identify tools via package managers, CLI-Hub, or binaries.
2. INSPECT: Parse `--help`, subcommands, and flags.
3. ASSESS: Evaluate security risk and deterministic execution.
4. INSTALL: Safely install or bundle standalone binaries.
5. VALIDATE: Test invocations and check JSON structured output.
6. USE: Execute via generated harness wrapper.
