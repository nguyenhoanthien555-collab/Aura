# 10. EXACTLY-ONCE VS AT-LEAST-ONCE

Do not falsely claim "exactly once" execution merely because the network layer is idempotent.

Separate:

```text
event delivery semantics
```

from:

```text
physical side-effect semantics
```

For example:

```text
launch_app
tap
type_text
```

may have side effects.

If a request times out after execution but before response:

```text
UNKNOWN
```

The system must not blindly execute the same side effect again unless the tool is explicitly idempotent or the device-side execution layer has a durable execution ID / replay protection.

Audit:

```text
toolCallId
run_id
invocation ID
execution ID
completed-report cache
```

and strengthen them if necessary.
