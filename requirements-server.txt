# 3.14 — which paired this file's old `sqlalchemy==2.0.36` with a Python
# that SQLAlchemy release had never seen, and the server stopped booting.
# See `.python-version` and `tests/test_deploy_startup.py`.

# 2.0.51, not 2.0.36. Python 3.14 made `typing.Union` an alias of
# `types.UnionType` (PEP 604), so SQLAlchemy's `make_union_type` — which
# called the unbound `Union.__getitem__(tuple)` — began raising
# `TypeError: descriptor '__getitem__' requires a 'typing.Union' object`
# while mapping the first `Mapped[str | None]` column it met. That is
# `memory.models.UserModelEntry.last_confirmed_at`, and it took the whole
# server down at import. Fixed upstream; this is the floor that contains it.
